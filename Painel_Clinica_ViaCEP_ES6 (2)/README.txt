# Painel de Saúde da Clínica

Projeto em JavaScript ES6+ com:
- Classes e atributos privados
- Herança com extends/super
- Modularização com import/export
- Manipulação do DOM
- Formulário com preventDefault
- Cálculo e classificação de IMC
- Consulta de CEP pela API ViaCEP usando fetch e async/await
