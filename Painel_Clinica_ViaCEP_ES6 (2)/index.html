Painel do Desenvolvedor — JSON e API

O que é JSON?

JSON significa JavaScript Object Notation. É um formato leve utilizado para organizar e transportar dados. As informações são estruturadas principalmente em pares de chave e valor, por exemplo: { "cidade": "São Paulo", "uf": "SP" }.

Como a requisição funciona no navegador?

O JavaScript utiliza o método fetch() para fazer uma requisição à internet. Nesse projeto, o navegador consulta a API do ViaCEP quando o usuário termina de digitar o CEP. A operação é assíncrona, portanto a página pode continuar funcionando sem precisar ser recarregada.

Como o JavaScript utiliza a resposta?

Depois que o servidor responde, utilizamos await resposta.json(). Esse método interpreta os dados recebidos em JSON e os transforma em um objeto JavaScript. Assim, podemos acessar informações como dados.localidade e dados.uf para preencher automaticamente o campo Cidade/UF.
