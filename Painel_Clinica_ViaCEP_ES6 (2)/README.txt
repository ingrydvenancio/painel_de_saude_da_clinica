# Painel de Saúde da Clínica

Projeto em JavaScript ES6+ com:
- Classes e atributos privados
- Herança com extends/super
- Modularização com import/export
- Manipulação do DOM
- Formulário com preventDefault
- Cálculo e classificação de IMC
- Consulta de CEP pela API ViaCEP usando fetch e async/await
- Explicação didática sobre JSON

## Como executar

Como o projeto utiliza módulos ES6 (`import`/`export`) e `fetch`, recomenda-se abrir pelo Live Server no VS Code.

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Instale/ative a extensão Live Server.
4. Clique com o botão direito em `index.html`.
5. Escolha "Open with Live Server".

O navegador precisa estar conectado à internet para a consulta do ViaCEP funcionar.
